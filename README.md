# Paper Wiki (Claude Code 버전)

읽었거나 읽을 논문을 정리하는 개인용 위키예요. 데이터는 내 PC의 JSON 파일로 저장되고, Claude Code가 논문을 넣고 정리해요.

## 필요한 것
- Python 3.8 이상 (추가 설치 없음)
- Claude Code (논문을 자동으로 넣거나 질문 탭을 쓸 때)

API 키는 필요 없고, 어디에도 저장하지 않아요.

## 실행
```
python serve.py
```
브라우저에서 `http://127.0.0.1:8765` 가 열려요. 끄려면 터미널에서 Ctrl+C.
`index.html` 파일을 더블클릭해서 열면 데이터를 불러오지 못해요. 꼭 `serve.py`로 여세요.

## 화면
| 탭 | 하는 일 |
| --- | --- |
| 홈 | 상태별 개수, 분야별 막대, **논문 연결 지도** (휠·두 손가락·버튼으로 확대/축소, 빈 곳 끌어 이동, 분야·공통 키워드로 찾기) |
| 카드 · 표 · 칸반 | 검색, 분야·상태·중요도·**무료/유료** 필터. 60편씩 나눠 보여 줘요 |
| 질문 | 위키에 정리된 논문 안에서만 답해요. 근거 논문 번호 `[#05]`를 달고, 없으면 없다고 말해요 |
| 인사이트 | 논문을 읽으며 떠오른 생각을 캔버스·카드·칸반으로 정리 |

- 참고문헌 추출: BibTeX · ACS · APA · IEEE · Nature
- 편집 중 실수로 창을 닫아도 수정 내용이 사라지지 않아요 (닫기 전에 묻고, 브라우저에 임시 저장)
- 같은 DOI·제목의 논문을 다시 넣으려 하면 알려 줘요

## 논문 넣기
이 폴더에서 Claude Code를 열고 이렇게 말하면 돼요.
```
읽을 논문 https://doi.org/10.48550/arXiv.1706.03762
읽는 중 10.1038/s41586-021-03819-2
pdfs/07_example2024.pdf 정리해서 넣어줘
```
Claude Code는 `CLAUDE.md`의 규칙과 `.claude/skills/paper-wiki-add` 절차를 따라 `data/papers/`에 파일을 만들고, 관련 논문끼리 연결하고, DOI로 무료/유료 여부도 확인해요. 열려 있는 화면에는 몇 초 안에 반영돼요.

화면에서 직접 추가·편집해도 같은 파일에 저장돼요.

## 질문하기
- **화면의 질문 탭**: `serve.py`가 내 PC의 Claude Code 명령(`claude`)을 불러 답해요. `claude` 명령이 없으면 질문 탭만 꺼져요. 답이 다 만들어지면 한 번에 보여 줘요.
- **Claude Code에서 바로**: `위키에 질문: 그래프 신경망으로 소재를 찾은 논문들을 비교해줘`처럼 물으면 같은 규칙(위키 안에서만 답하기)으로 답해요.

## 주요 규칙 (자세한 건 CLAUDE.md)
- 미출판 원고로 보이는 PDF는 검색하지 않고, 넣기 전에 물어봐요.
- Claude는 문제·방법·결과·논문이 밝힌 한계까지만 적어요. 흥미로운 점·궁금한 점·인사이트는 직접 쓰는 칸이에요.
- 관련 논문은 소재·방법이 같거나, 서로 보완하거나, 후속 연구이거나, 비교 대상일 때만 연결해요.
- 관리 번호(#01, #02…)는 `pdfs/`의 PDF 파일 번호와 맞춰요.

## 폴더
| 경로 | 내용 |
| --- | --- |
| `data/papers/` | 논문 1편 = JSON 1개 |
| `data/insights/` | 연구 인사이트 (직접 작성) |
| `data/layout/` | 연결 지도 점 위치 |
| `data/qa/` | 질문 탭 기록 |
| `pdfs/` | 논문 PDF |
| `config.json` | 화면 제목과 분야 문구 |
| `tools/check_data.py` | 데이터 점검 |
| `tools/import_backup.py` | claude.ai 판 위키의 JSON 백업 가져오기 |

## claude.ai 판 위키에서 데이터 가져오기
claude.ai 위키에서 **백업 → JSON으로 백업**을 받은 뒤:
```
python tools/import_backup.py paper-wiki-backup_YYYY-MM-DD.json
```

## git에 올릴 때
- 기본 설정으로는 **코드만 올라가요.** `data/` 안의 내 논문·메모·인사이트·질문 기록, `pdfs/`, 백업 JSON은 `.gitignore`로 빠져요.
- 내 데이터도 올리고 싶다면 비공개 저장소를 쓰고, `.gitignore`의 `data/...` 줄을 지우세요.
- 다른 사람이 쓸 때는 `config.json`의 제목·분야 문구만 바꾸면 돼요.
